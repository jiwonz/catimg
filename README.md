# catimg
Cat and Preview your images directly in terminal using [sixel](https://en.wikipedia.org/wiki/Sixel).

## Usage
> [!NOTE]
> Image previewing only works in sixel-supported terminals!
```sh
catimg image-to-preview.jpg
```

## Installation
### via [pesde](https://pesde.dev/)
```sh
pesde add jiwonz/catimg -t lune
pesde install
```

### via cargo
```sh
cargo install catimg
```

### via [GitHub Releases](https://github.com/jiwonz/catimg/releases)
